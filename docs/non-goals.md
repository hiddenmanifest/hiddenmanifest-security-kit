# Non-Goals

This repository is intentionally not a full open-source copy of the Hidden Manifest product.

It does not include:

- Production 0x or DEX routing implementation.
- Affiliate fee configuration or monetization logic.
- Broadcaster service implementation.
- Redis, Phoenix, or hosted backend code.
- Market-data ingestion and alert workers.
- Deployment files or production infrastructure.
- API keys, provider credentials, or private endpoints.
- Product analytics or operational controls.

The goal is to expose the code that users and auditors need for trust: browser vault cryptography, recovery-envelope shape, browser RAILGUN boundaries, transaction safety helpers, and public API contracts.
