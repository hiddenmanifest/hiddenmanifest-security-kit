# @hiddenmanifest/vault-crypto

Vault cryptography helpers for Hidden Manifest.

This package contains browser-safe primitives for:

- PBKDF2-SHA256 vault key derivation.
- Domain-separated RAILGUN and recovery envelope keys.
- AES-256-GCM encryption and decryption.
- Vault recovery envelope validation.
- BIP39 mnemonic and salt generation.
- Stable wallet-signature message construction.

It does not include server storage, production APIs, or hosted infrastructure.
